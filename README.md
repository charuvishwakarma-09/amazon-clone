# 🛒 Amazon Clone

A responsive **Amazon-inspired e-commerce website** built using **HTML5 and CSS3**.

## ✨ Features

* Amazon-style responsive navigation bar
* Search bar and category selector
* Product categories
* Today's Deals section
* Popular Products section
* Best Sellers CSS carousel
* Promotional banners
* Sign-in section
* Responsive footer
* Hover effects and smooth transitions
* Fully responsive for desktop, tablet and mobile

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Media Queries
* CSS Variables

## 📂 Project Structure

```text
Amazon Clone/
├── index.html
├── style.css
├── images/
└── README.md
```

## ▶️ How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Open `index.html` using Live Server or directly in a browser.
